# Car Ore Mod

Adds car-themed ores and selling stations to Minecraft

## Features

- Adds car-themed ores to the game
- Includes a car selling station block

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod JAR file
2. Place it in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

### Mining Car Ores

- Find and mine car ores in the world
- Car ores can be crafted into car ore blocks

### Selling Cars

- Place the car selling station block
- Interact with it to sell your cars

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
